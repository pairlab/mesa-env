# Acknowledgements

Our codebase is built using resources from the following projects:

- Our framework is built on top of the code release from [MimicLabs](https://robo-mimiclabs.github.io/)
- Our data generation code is based on [MimicGen](https://github.com/NVlabs/mimicgen)
- We train our PI models using [OpenPI](https://github.com/Physical-Intelligence/openpi)
- We use [LeRobot](https://github.com/huggingface/lerobot) as our go-to dataset format
- We sourced most of our assets from [RoboCasa](https://github.com/robocasa/robocasa)
- The BDDL format we used is a descendant of that from [Libero](https://github.com/Lifelong-Robot-Learning/LIBERO)
- We make heavy use of [tyro](https://github.com/brentyi/tyro) for command line argument parsing
